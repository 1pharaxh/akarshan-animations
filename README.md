# A collection of delightful **animations** & micro-interactions 
This repo is a collection of delightful **animations** & micro-interactions created using **motion/react**. All interactions are handcrafted. 

## Installation
To use the animations in this repository, you can clone the repository and install the dependencies:
```bash
npm run install
```
Then, you can start the development server:
```bash
npm run dev
```
